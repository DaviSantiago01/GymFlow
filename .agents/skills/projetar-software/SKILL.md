O projeto de software é feito a partir da especificação de uma ou mais funcionalidades e envolve projetar:

1) contextos delimitados
2) objetos de valor
3) entidades
4) agregados
5) associações
6) serviços
7) repositórios

Ao final, o modelo é validado com [validar-modelo](../validar-modelo/SKILL.md).

Ver exemplo em [references/REFERENCE.md](references/REFERENCE.md).

Ver [projetar-contextos-delimitados](../projetar-contextos-delimitados/SKILL.md).
